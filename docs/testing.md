# 测试策略

- 数值测试使用手算边界、解析性质或独立枚举作为预期值。
- 因果解码器测试覆盖未来 token 不可见、模态权重、填充掩码和音频编码器梯度传播。
- JSONL、音频帧与状态机同时覆盖合法输入、截断输入和关闭后操作。
- 公共 API 使用完整签名快照，新增、删除、默认值和数据字段变化都会触发失败。
- 神经网络测试标记为 `model`；核心测试无需安装 PyTorch。

```bash
python -m pytest -q -m 'not model'
python -m pytest -q -m model
```

CI 使用 Python 3.10、3.12、3.13 运行核心测试，并单独运行 CPU 模型测试。
